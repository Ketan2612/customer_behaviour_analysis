# Data Analytics Project

## Overview

This project demonstrates an end-to-end data analytics workflow, covering data ingestion, exploration, cleaning, analysis using SQL, and visualization through an interactive dashboard. The goal is to showcase practical data analytics skills commonly used in real-world business scenarios, with a strong focus on clarity, insights, and decision-making.

## Dataset

* Source: Public or provided dataset (CSV/Excel format)
* Size: Medium-sized dataset suitable for analytics and visualization
* Description: Contains structured data used to analyze trends, patterns, and key performance metrics

> Note: The dataset is loaded and processed using Python before being stored and queried in relational databases.

## Tools & Technologies

* **Programming Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib/Seaborn (for EDA)
* **Databases:** PostgreSQL, MySQL, SQL Server
* **SQL:** Data querying, aggregation, and analysis
* **Visualization:** Power BI
* **Reporting:** Written analytical report (PDF/Doc)
* **Presentation:** Gamma (PPT-style presentation)

## Project Workflow

1. **Data Loading**

   * Imported the dataset into Python using Pandas
   * Performed initial inspection of structure and data types

2. **Exploratory Data Analysis (EDA)**

   * Analyzed distributions, trends, and outliers
   * Identified missing values and data quality issues
   * Generated summary statistics and visualizations

3. **Data Cleaning & Preparation**

   * Handled missing and inconsistent values
   * Removed duplicates and corrected data types
   * Created derived columns where necessary

4. **Database & SQL Analysis**

   * Loaded cleaned data into PostgreSQL / MySQL / SQL Server
   * Wrote SQL queries for:

     * Aggregations and KPIs
     * Filtering and joins
     * Trend and performance analysis

5. **Dashboard Development**

   * Built an interactive Power BI dashboard
   * Included KPIs, charts, and filters for user-driven analysis

6. **Reporting & Presentation**

   * Created a concise analytical report summarizing insights
   * Developed a professional presentation using Gamma to communicate findings

## Dashboard

The Power BI dashboard highlights:

* Key performance indicators (KPIs)
* Trends and patterns over time
* Category-wise and segment-level analysis
* Interactive filters for deeper exploration

## Results

* Identified key trends and patterns in the data
* Highlighted actionable insights relevant to business decision-making
* Demonstrated how data can be transformed into meaningful visual stories

## Insights

* Clothing generates the highest revenue among all categories.
* Most purchases are made by adults aged 25–40.
* Subscribers spend 18% more on average than non-subscribers.
* Express shipping customers tend to have higher purchase values.

## How to Run the Project

1. Clone this repository
2. Set up a Python environment and install required libraries
3. Run the Python scripts/notebooks for data loading, EDA, and cleaning
4. Load the cleaned data into your preferred SQL database (PostgreSQL, MySQL, or SQL Server)
5. Execute the provided SQL queries
6. Open the Power BI file to explore the dashboard
7. Review the report and presentation for summarized insights
